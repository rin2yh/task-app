# CLAUDE.md

## Layout

- `app/` — Cloudflare Worker + Vite/React. **Run pnpm here.**
- `terraform/` — D1 + Worker + secrets (state outside the repo).
- `docs/oauth.md` — GitHub OAuth setup.
- Toolchain: @mise.toml (`mise trust && mise install`).

## Commands

@app/package.json. Project gate: `pnpm lint && pnpm typecheck && pnpm test && pnpm test:server`.

## Architecture

- **Inertia/SSR**: `c.render('<name>', props)` → `app/pages/<name>.tsx` (kebab-case); always spread `buildSharedProps(c)`. Gitignored `pages.gen.ts` is regenerated by `pnpm dev`/`build`, required for typecheck.
- **Auth**: `server/auth/oauth/factory.ts` swaps to `FakeGitHubOAuthClient` on `NODE_ENV === 'test'` (Vite DCEs in prod). Mutating routes: `requireAuth` + `csrfGuard`; CSRF = `csrf` cookie + `X-CSRF-Token` header == session csrfToken. `requireAuth` → 409 + `X-Inertia-Location` (Inertia) / 302 — never JSON 401.
- **Data**: Drizzle on D1 (`server/db/schema.ts`); repos scope by `projects.ownerId`, cross-tenant → `null` → `NotFound`. ULIDs: `server/db/ulid.ts`.
- **Ordering**: float `position` midpoint insertion (`server/lib/position.ts`, 1e-6 rebalance); `moveTask` falls back to `rebalance()` on gap collapse. No alternate schemes.
- **Aliases** (`tsconfig.json` + `config/vite.config.ts` + both vitest configs): `@/` → `app/`, plus `@server/`, `@client/`, `@shared/`.
- **Frontend**: React 19 + Inertia + Tailwind v4 + shadcn/ui (`new-york`, `@/components/ui`) + `@dnd-kit`; optimistic board: `client/hooks/use-optimistic-board.ts`.
- **PWA**: `vite-plugin-pwa` injectManifest, SW `client/pwa/sw.ts`; `register.ts` is `import.meta.env.DEV`-guarded — verify via `pnpm build && pnpm preview`.
- **Cron**: `server/index.ts` `scheduled` → `purgeExpired` (`0 3 * * *`).
- **Tests**: `tests/helpers.ts` (`applyMigrations`, `createTestUser`); don't touch D1 directly.
