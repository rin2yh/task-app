# CLAUDE.md

## Layout

- `app/` — Cloudflare Worker + Vite/React. **Run pnpm here.**
- `terraform/` — D1 + Worker scaffold (state outside the repo).
- Toolchain: @mise.toml (`mise trust && mise install`).

## Commands

@app/package.json. Project gate: `pnpm lint && pnpm typecheck && pnpm test && pnpm test:server`.

## Architecture

- **Inertia/SSR**: `c.render('<name>', props)` → `app/pages/<name>.tsx` (kebab-case). `pages.gen.ts` is gitignored, regenerated by `pnpm dev`/`build`, required for typecheck. Always spread `buildSharedProps(c)` into props.
- **Auth**: `server/auth/oauth/factory.ts` returns `FakeGitHubOAuthClient` when `NODE_ENV === 'test'` (Vite DCEs it in prod). Mutating routes chain `requireAuth` + `csrfGuard`. CSRF = `csrf` cookie + `X-CSRF-Token` header == session csrfToken. `requireAuth` returns 409 + `X-Inertia-Location` for Inertia, else 302 — don't return JSON 401.
- **Data**: Drizzle on D1; schema in `server/db/schema.ts`. Repos enforce ownership via `projects.ownerId`; cross-tenant → `null` → `NotFound`. ULIDs from `server/db/ulid.ts`.
- **Ordering**: float `position` with midpoint insertion (`server/lib/position.ts`, 1e-6 rebalance threshold); `moveTask` falls back to `rebalance()` on gap collapse. No alternate ordering schemes.
- **Aliases** (`tsconfig.json` + `config/vite.config.ts` + both vitest configs): `@/` → `app/`, `@server/`, `@client/`, `@shared/`.
- **Frontend**: React 19 + Inertia + Tailwind v4 + shadcn/ui (`new-york`, `@/components/ui`); `@dnd-kit`; optimistic board in `client/hooks/use-optimistic-board.ts`.
- **PWA**: `vite-plugin-pwa` injectManifest, SW at `client/pwa/sw.ts`. `register.ts` is `import.meta.env.DEV`-guarded — verify via `pnpm build && pnpm preview`.
- **Cron**: `server/index.ts` exports `scheduled` → `purgeExpired` (`0 3 * * *`).
- **Tests**: use `tests/helpers.ts` (`applyMigrations`, `createTestUser`); don't touch D1 directly.
