# CLAUDE.md

## Layout

- `app/` — Cloudflare Worker + Vite/React. **Run pnpm here.**
- `terraform/` — D1 + Worker scaffold (state outside the repo).
- Toolchain: @mise.toml (`mise trust && mise install`).

## Commands

@app/package.json. Project gate: `pnpm lint && pnpm typecheck && pnpm test && pnpm test:server`.

## Architecture

- **Inertia/SSR**: `c.render('<name>', props)` → `app/pages/<name>.tsx` (kebab-case); always spread `buildSharedProps(c)`. `pages.gen.ts` is gitignored but required for typecheck — regenerated by `pnpm dev`/`build`.
- **Auth**: OAuth factory returns the fake client on `NODE_ENV === 'test'`. Mutating routes chain `requireAuth` + `csrfGuard`. `requireAuth` → 409 + `X-Inertia-Location` for Inertia, else 302 — never JSON 401.
- **Data**: repos must scope by `projects.ownerId`; cross-tenant lookups → `null` → `NotFound`.
- **Ordering**: float `position` with midpoint insertion; `moveTask` falls back to `rebalance()` when the gap collapses below 1e-6.
- **Aliases**: keep `tsconfig.json`, `config/vite.ts`, `config/vitest.ts`, and `config/vitest.workers.ts` in sync.
- **PWA**: `register.ts` is `import.meta.env.DEV`-guarded — verify SW changes via `pnpm build && pnpm preview`, not `pnpm dev`.
- **Tests**: use `tests/helpers.ts`; don't touch D1 directly.
